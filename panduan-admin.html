1 Akses Masuk Admin & Pengaturan Kredensial

Untuk masuk ke panel pengelolaan data admin, silakan ikuti petunjuk berikut:

  • URL Portal Resmi: https://gamkisumut.my.id
  • Menu Akses: Klik menu "Login Admin" di pojok kanan atas navigasi website.
Kredensial Login Admin:

Username: (Tersimpan di Sheet Admin)

Password: (Tersimpan di Sheet Admin)

Cara Mengubah Username & Password:
  1. Buka Google Sheets Database Panitia.
  2. Pilih tab "Admin" di bagian bawah.
  3. Ganti Username di Kolom A Row 2 dan Password di Kolom B Row 2.
  4. Perubahan langsung aktif secara real-time!
2 Modul Dashboard Utama & Control Cloud Server

Halaman Dashboard (/dashboard) memuat 3 indikator statistik utama & panel kontrol status portal:

Menunggu Verifikasi

Pendaftar baru yang berkasnya perlu ditinjau

Peserta Resmi (ACC)

Pendaftar yang disetujui & memiliki ID Peserta

Hadir Hari H

Peserta yang telah check-in di lokasi acara
Pengaturan Portal Global (Cloud Control):
  • Status Pendaftaran: Ubah ke Buka atau Tutup. Jika ditutup, form pendaftaran di website publik otomatis tersembunyi.
  • No. WA Helpdesk Panitia: Nomor WA bantuan yang tampil di tombol kontak publik.
  • Lokasi Kegiatan: Mengatur alamat resmi (Default: Bank Sumut Lt. 10, Jl. Imam Bonjol Medan).
3 Modul Verifikasi Berkas & Notifikasi Email Otomatis

Menu Verifikasi Pendaftaran (/admin-pendaftaran) digunakan untuk meninjau berkas UMKM:

  1. Pencarian & Filter Data: Gunakan kata kunci Nama UMKM, Pemilik, atau ID Pendaftaran (REG-2026-XXXX) serta filter bidang usaha.
  2. Pemeriksaan Berkas HD: Klik tombol Detail untuk melihat perizinan (NIB, NPWP, PIRT, Halal) dan foto produk ukuran jernih HD.
  3. Proses Aksi Verifikasi:
    • Tombol Terima (ACC): Mengubah status pendaftar menjadi Diterima, menerbitkan ID Peserta Resmi (PST-2026-XXXX), dan mengirimkan Email Kelulusan Otomatis via Brevo API ke pendaftar.
    • Tombol Tolak Pendaftaran: Mengisi alasan penolakan (misal: Foto produk buram) dan mengirimkan Email Penolakan Otomatis berisi petunjuk pendaftaran ulang.
4 Modul Data Peserta, Export Excel & Check-In Hari H
Export Data Excel (1-Klik):

Pada menu Data Peserta (/admin-peserta):

  • Klik tombol "Export Data ke Excel".
  • File .xls berformat rapi memuat 24+ kolom data akan terunduh instan.
Check-In Kehadiran Hari H (Sub-Second):

Pada menu Registrasi Hari H (/admin-registrasi) di lokasi acara pada Jum'at 25 Sep 2026:

  1. Ketik 4 digit belakang ID Peserta (misal 0001 dari PST-2026-0001).
  2. Preview live peserta akan muncul secara otomatis.
  3. Klik "Catat Hadir" (atau tekan ENTER). Kehadiran tercatat instan dengan ID HDR-2026-XXXX!
